# Yến Hà Tới Đây: Portfolio

React + TypeScript + Tailwind CSS v4 + Framer Motion + Lucide React, build bằng Vite.

## Chạy
```bash
pnpm install
pnpm dev        # http://localhost:3000 (host 0.0.0.0)
pnpm run build  # ra thư mục dist
```

## Sửa nội dung
Toàn bộ chữ, ảnh và link nằm trong `src/data/content.ts`. Ảnh để ở `public/images/`.

## Ghi chú
Thư mục `preview/` chỉ dùng để build bản xem trước khi không cài được package. Có thể xoá thư mục này.
